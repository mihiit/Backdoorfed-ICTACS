# Experiment artifact inventory

The files in `completed/` are the available outputs from completed prior experiments. Exact seed counts and configurations are described in each report or encoded in each raw CSV. The archive includes full-population mechanism analysis, alpha sweep, assumed-f sensitivity, MAD threshold sensitivity, malicious-client-fraction sweep, and fresh-20/client-rank diagnostics where files were available.

The 100-seed CIFAR-10 CNN experiment is a runnable script, not a completed result. Its outputs are not included because the full run has not been executed.
